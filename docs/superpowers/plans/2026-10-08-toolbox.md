# trekm Toolbox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task if the user chooses native execution. Steps use checkbox syntax for tracking.

**Goal:** Build the approved static toolbox with links to FuelLog and Eternal Timer, using artwork from their own sites.

**Architecture:** Plain HTML and CSS with a local SVG favicon. Each app remains independent. Documentation lives alongside the public files, but only the three public assets need deployment.

**Tech Stack:** HTML5, CSS, SVG; a local static server and browser for verification. No dependencies or build step.

**Spec:** ../specs/2026-10-08-toolbox-design.md

## Global constraints

- Public target: `https://pwa.trekm.com/`.
- App targets: `https://fuel.trekm.com/` and `https://timers.trekm.com/`.
- Do not copy app artwork into this repository or create replacement app symbols.
- Load artwork directly from each app's `icons/icon.svg`.
- No package manager, application server or runtime JavaScript is required.
- Each app retains its own folder, repository, storage and service worker.
- Keep names, descriptions and links usable when artwork is unavailable.
- Support 320 px screens, keyboard navigation and readable contrast.
- Do not publish private development paths or claim unverified app availability.

## Review focus

1. Artwork blocked or unavailable: navigation remains usable, with no broken-image clutter or layout shift.
2. Narrow screen or enlarged text: all content stays readable without horizontal scrolling.
3. Keyboard navigation: both app links have visible focus and descriptive labels.
4. Remote dependencies: only the two app hosts are used for artwork, with no referrer sent.
5. Public deployment: only public assets are uploaded; the documentation and Git directory are excluded.
